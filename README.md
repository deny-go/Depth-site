# Depth Studio — GitHub Pages

Готовая статическая сборка Depth Studio. Обработка изображений выполняется в браузере посетителя.

Сайт: https://deny-go.github.io/Depth-site/

Публичный репозиторий содержит только файлы опубликованного сайта и лицензии. Разработка ведётся отдельно в приватном репозитории.
Для работы модели нужен интернет: веса загружаются с Hugging Face; фотографии остаются на устройстве пользователя.

Не изменяйте произвольно версии ONNX Runtime: файлы runtime согласованы с использованной версией Transformers.js.
